# 模块二：特征工程变更说明

**版本**: v2.0 (7D版本)
**日期**: 2026-05-17
**核心变更**: 10维 → 7维全局独立核心特征

---

## 一、变更背景

盾构掘进的核心物理过程是"刀盘旋转推进"——推力驱动刀盘向前，扭矩传递到刀盘，转速决定切削次数，推进速度决定贯入深度。这五个量构成完整的机械功率方程，也是计算三个高阶不变量（SE、FPI、TPI）的基础。

**原有的问题**：如果将高阶不变量（SE、FPI、TPI）与底层机械参数（F_v、T、v_forward、RPM、power_proxy）混合使用，会导致**多重共线性**——因为SE/FPI/TPI本身就是从这些底层参数派生而来的。

**解决方案**：严格遵循"物理导向的特征平替原则"——保留3个高阶不变量，强制剔除所有参与计算的底层机械参数，然后从电气/热力/流体簇中通过贪心选取算法获取4个跨域独立特征。

## 二、7维全局独立核心特征

| 编号 | 特征名 | 物理场 | 物理意义 |
|------|--------|--------|---------|
| 1 | SE | 能效/机械 | 切削比能（单位体积岩石切削能耗） |
| 2 | FPI | 能效/机械 | 推力贯入度指数（掌子面抗压强度） |
| 3 | TPI | 能效/机械 | 扭矩贯入度指数（剪切摩擦阻力） |

| 5 | 主油箱油温 | 热力 | 热能累积迟滞效应 |
| 6 | 泥水仓顶部1压力 | 流体 | 水土压力边界稳定性 |
| 7 | 排浆密度 | 流体 | 出渣率/携岩能力 |

## 三、贪心选取算法

### 3.1 算法原理

在物理导向特征平替原则下，3个高阶不变量（SE、FPI、TPI）已经固定。现在需要从剩余的三个物理簇（电气、热力、流体）中各选取若干特征。

**核心问题**：为什么选这一个而不是另一个？

**答案**：因为在**全局上下文**中（已选中所有其他簇特征），该候选特征与已选集合的**平均Spearman相关性最低**，即最独立。

### 3.2 算法步骤

```python
def greedy_select_global(df, candidates, already_selected, max_features):
    """
    全局贪心选取算法

    输入：
      - df: 数据DataFrame
      - candidates: 当前簇的候选特征列表
      - already_selected: 已经选中的特征列表（来自其他簇）
      - max_features: 最多选几个

    步骤：
      1. 过滤常量列（std < 1e-6）
      2. 计算所有候选特征之间的Spearman相关矩阵
      3. 对每个候选c，计算其与already_selected的全局平均|r|
      4. 选取全局平均|r|最低的特征（最独立）
      5. 重复直至选满max_features
    """
```

### 3.3 贪心选取过程

#### 第一步：固定高阶不变量（3个）

已选特征 = [SE, FPI, TPI]

这三个特征虽然彼此之间有较高相关性（SE↔TPI: r=0.941），但这是**物理设计层面的主动妥协**，因为它们各自从不同角度刻画切削过程。

#### 第二步：电气簇选取（从5个候选中选1个）

候选特征：P2.1泵电流、P0.1泵电流、P0.2泵电流、P1.1泵电流、P0.3泵电流

计算每个候选与已选特征[SE, FPI, TPI]的全局平均|r|：

| 候选特征 | 全局平均 \|r\| | 排名 |
|----------|---------------|------|
| **P2.1泵电流** | **最低** | **1（选中）** |
| P0.1泵电流 | 较高 | 2 |
| P0.2泵电流 | 较高 | 3 |
| P1.1泵电流 | 较高 | 4 |
| P0.3泵电流 | 较高 | 5 |

**结论**：P2.1泵电流与SE/FPI/TPI的全局平均相关性最低，因此被选中。

已选特征 = [SE, FPI, TPI, P2.1泵电流]

#### 第三步：热力簇选取（从5个候选中选1个）

候选特征：主油箱油温、齿轮油温、齿轮油温2、破碎机温度、内循环水温度

计算每个候选与已选特征[SE, FPI, TPI, P2.1泵电流]的全局平均|r|：

| 候选特征 | 全局平均 \|r\| | 排名 |
|----------|---------------|------|
| **主油箱油温** | **最低** | **1（选中）** |
| 齿轮油温 | 较高 | 2 |
| 齿轮油温2 | 较高 | 3 |
| 破碎机温度 | 较高 | 4 |
| 内循环水温度 | 较高 | 5 |

**结论**：主油箱油温与SE/FPI/TPI/P2.1泵电流的全局平均相关性最低，因此被选中。

已选特征 = [SE, FPI, TPI, P2.1泵电流, 主油箱油温]

#### 第四步：流体簇选取（从11个候选中选2个）

候选特征：泥水仓顶部1压力、泥水仓顶部2压力、泥水仓左中下压力、泥水仓右中上压力、主进浆流量、主排浆流量、进浆密度、排浆密度、进浆压力、泥水仓液位、内循环水压力

计算每个候选与已选特征[SE, FPI, TPI, P2.1泵电流, 主油箱油温]的全局平均|r|：

| 候选特征 | 全局平均 \|r\| | 排名 |
|----------|---------------|------|
| **泥水仓顶部1压力** | **最低** | **1（选中）** |
| **排浆密度** | **次低** | **2（选中）** |
| 泥水仓顶部2压力 | 较高 | 3 |
| 泥水仓左中下压力 | 较高 | 4 |
| ... | ... | ... |

**结论**：泥水仓顶部1压力和排浆密度与前5个已选特征的全局平均相关性最低，因此被选中。

已选特征 = [SE, FPI, TPI, P2.1泵电流, 主油箱油温, 泥水仓顶部1压力, 排浆密度]

### 高相关对分析（|r|>0.7）

| 特征对 | r值 | 说明 |
|--------|-----|------|
| SE ↔ TPI | +0.941 | 高阶不变量内部（同源派生） |
| SE ↔ FPI | +0.765 | 高阶不变量内部（同源派生） |
| FPI ↔ TPI | +0.774 | 高阶不变量内部（同源派生） |

**说明**：这三个高相关对均存在于3个高阶不变量之间，这是物理设计层面的主动妥协，三者各自从不同物理角度刻画切削过程，不可替代。

### 跨簇特征独立性

跨簇的4个特征（P2.1泵电流、主油箱油温、泥水仓顶部1压力、排浆密度）与其他特征的最大|r|：

| 特征 | 与其他特征最大\|r\| | 独立性评级 |
|------|---------------------|-----------|
| P2.1泵电流 | 0.504（与排浆密度） | 弱相关 |
| 主油箱油温 | 0.160（与FPI） | 极强独立 |
| 泥水仓顶部1压力 | 0.053（与P2.1泵电流） | 极强独立 |
| 排浆密度 | 0.504（与P2.1泵电流） | 弱相关 |

## 五、网络拓扑意义

| 指标 | 值 |
|------|-----|
| 输入维度 | 7 |
| 潜在维度 | 16 |
| 压缩比 | 7/16 ≈ 0.44 |
| 输入规模 | 60×7 = 420 通道/帧 |
| 原始1390列 | 1390列 = 83400 通道/帧 |

压缩比0.44处于合理范围（0.3~0.7），确保TS-VAE学习"隐式协同传导规律"而非"线性同构复制"。
