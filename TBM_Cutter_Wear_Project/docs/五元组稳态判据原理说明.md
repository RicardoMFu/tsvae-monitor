# 五元组稳态判据原理说明

## 一、判据设计背景

盾构机掘进过程中，数据中存在大量停机、空转、起步建压等非纯掘进状态。若直接使用全量数据训练，会引入大量噪声样本，严重影响刀具磨损状态识别的准确性。

传统的停机判断仅依据"推进速度>0"，过于粗糙，无法区分：
- 正常掘进中的极低速推进
- 空转摩擦（刀盘转但推力极低）
- 起步建压阶段（推力建立但刀盘未转动）

## 二、五元组稳态判据定义

本管线采用**五元组联合判定**策略，五个核心施工参数均为正值时判定为正常推进，任一参数为零时判定为停机。

| 参数 | 单位 | 正常推进阈值 | 物理意义 |
|------|------|-------------|----------|
| 总推进力 F | kN | F > 0 | 刀盘克服掌子面阻抗的必需推力 |
| 刀盘扭矩 T | kN·m | T > 0 | 刀盘旋转切削克服岩土阻力 |
| 推进速度 v | mm/min | v > 0 | 盾构机体推进速率 |
| 刀盘转速 N | rpm | N > 0 | 刀盘旋转速度 |
| 贯入度 p | mm/rev | p > 0 | 刀盘每转切入岩土深度 |

**判定逻辑（AND）**：
```
正常推进 ⟺ (F > 0) ∧ (T > 0) ∧ (v > 0) ∧ (N > 0) ∧ (p > 0)
停机状态 ⟺ (F = 0) ∨ (T = 0) ∨ (v = 0) ∨ (N = 0) ∨ (p = 0)
```

## 三、各参数物理意义

### 3.1 总推进力 (F)
盾构机推进液压系统施加于刀盘的轴向推力。正常掘进时需克服掌子面阻抗、地层摩擦力及刀具切削阻力。F > 0 表示推进系统处于激活状态。

### 3.2 刀盘扭矩 (T)
驱动刀盘旋转的电机/液压扭矩。正常掘进时需克服岩土的切削阻力和刀盘与掌子面之间的摩擦阻力。T > 0 表示刀盘处于切削状态。

### 3.3 推进速度 (v)
盾构机沿隧道轴向的推进速率。正常掘进时刀盘切入岩土，机体向前推进。v > 0 表示机体处于推进运动中。

### 3.4 刀盘转速 (N)
刀盘旋转的角速度。正常掘进时刀盘持续旋转进行切削作业。N > 0 表示刀盘处于旋转状态。

### 3.5 贯入度 (p)
刀盘每旋转一周机体向前推进的距离，直接反映刀盘切入岩土的深度。p > 0 表示存在有效的切入过程。

## 四、停机状态识别

当任一参数为 0 时，表明掘进过程中断，对应以下典型工况：

| 停机参数 | 典型工况 |
|---------|---------|
| F = 0 | 液压系统待命、换步、管片拼装 |
| T = 0 | 刀盘空转、刀盘停转检修 |
| v = 0 | 机体静止、模式切换 |
| N = 0 | 刀盘停转、开仓检修 |
| p = 0 | 刀盘空转、无有效切入 |

## 五、连续性约束

除五元组判定外，增加时间连续性约束：稳态段持续时间 ≥ 300秒。

**目的**：排除短暂的参数波动（如推进速度瞬间抖动）和碎片化工况，确保提取的样本来自稳定、持续的掘进过程。

## 六、与传统方法的对比

| 方法 | 判断标准 | 优点 | 缺点 |
|------|---------|------|------|
| 旧方法（速度>0） | v > 0 | 简单 | 无法排除空转、假推进 |
| 本方法（五元组） | 五值全 > 0 | 物理意义明确、可排除空转和建压阶段 | 阈值敏感性低（仅需>0） |

## 七、优势分析

1. **物理意义明确**：五个参数覆盖了盾构机掘进的核心动力学要素
2. **抗干扰能力强**：任一参数为零即判定停机，有效排除非纯掘进状态
3. **阈值简洁**：仅需判断 > 0，无需复杂阈值设定
4. **贯入度替换泥水仓压力**：贯入度直接反映刀盘切入效果，比泥水仓压力更具物理代表性
